# Changelog

## 1.0.0 — 2026-08-27

- Toggle the current track in Spotify's Liked Songs with one global shortcut.
- Add tracks to the playlist they were played from when that playlist is editable.
- Remove only playlist entries previously added by the utility when unliking.
- Authenticate locally with OAuth PKCE and store tokens in macOS Keychain.
- Show native notifications with a custom icon and remove them automatically.
- Support Apple silicon and Intel Macs running macOS 13 or newer.
